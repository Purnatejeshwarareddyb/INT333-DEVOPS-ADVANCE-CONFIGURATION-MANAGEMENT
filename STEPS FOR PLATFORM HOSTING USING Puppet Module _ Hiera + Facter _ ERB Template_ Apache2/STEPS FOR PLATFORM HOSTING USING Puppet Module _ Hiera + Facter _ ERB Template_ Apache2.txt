# Practical 5 — Dynamic Employee Portal Using Puppet

## 1. Go to Puppet module directory

```bash
cd /etc/puppet/code/environments/production/modules
```

**Why:** Opens the location where Puppet modules are stored.

---

## 2. Create the Employee Portal module

```bash
sudo mkdir -p employee_portal/{manifests,templates}
```

**Why:** Creates the module with folders for Puppet code and the HTML template.

Check:

```bash
ls -R employee_portal
```

---

# 3. Create Hiera data directory

```bash
cd /etc/puppet/code/environments/production
sudo mkdir -p data
```

**Why:** Hiera stores configuration/data separately from Puppet code.

---

# 4. Create `common.yaml`

```bash
sudo nano data/common.yaml
```

Put exactly:

```yaml
portal_name: "Company Employee Information Portal"
department: "Information Technology"
company_message: "Welcome to the Company Employee Portal"
```

Save:

**Ctrl + O → Enter → Ctrl + X**

**Why:** Stores the portal's configurable information using Hiera.

---

# 5. Configure Hiera

```bash
sudo nano /etc/puppet/hiera.yaml
```

Put exactly:

```yaml
---
version: 5

defaults:
  datadir: /etc/puppet/code/environments/%{environment}/data
  data_hash: yaml_data

hierarchy:
  - name: Common
    path: common.yaml
```

Save:

**Ctrl + O → Enter → Ctrl + X**

**Why:** Tells Puppet where to find the Hiera data file.

> Your installation uses `/etc/puppet/code/...`, so use this path instead of `/etc/puppetlabs/code/...` from some standard versions of the practical.


```puppet
class employee_portal {

  $portal_name = lookup('portal_name')

    require => File['/var/www/html/employee_portal'],
  }

}
```

Save:

**Ctrl + O → Enter → Ctrl + X**

**Why:** This is the main Puppet manifest. It installs Apache, starts it, creates the portal directory, and generates the HTML page.

```bash
sudo puppet parser validate /etc/puppet/code/environments/production/modules/employee_portal/manifests/init.pp
```

**Why:** Checks the Puppet syntax.

**No output = correct.**

# 10. Validate `site.pp`

```bash
sudo puppet parser validate /etc/puppet/code/environments/production/manifests/site.pp
```

**Why:** Checks the `site.pp` syntax.

**No output = correct.**

---

# 11. Test Hiera

```bash
sudo puppet lookup portal_name --environment production
```

Expected:

```text
--- Company Employee Information Portal
```

Then:

```bash
sudo puppet lookup department --environment production
```

Expected:

```text
--- Information Technology
```

Then:

```bash
sudo puppet lookup company_message --environment production
```

Expected:

```text
--- Welcome to the Company Employee Portal
```

**Why:** Confirms Puppet can correctly read the Hiera values.

---

# 12. Test Facter

```bash
facter networking.hostname
```

```bash
facter networking.ip
```

```bash
facter os.name
```

Expected values on your VM:

```text
puppetmaster
10.0.2.15
Ubuntu
```

**Why:** Facter provides system information automatically to Puppet.

---

# 13. Run Puppet Agent

```bash
sudo puppet agent --test
```

**Why:** The Puppet Agent contacts the Puppet Master, receives the catalog, and applies the configuration.

You should see something similar to:

```text
Notice: Requesting catalog from puppetmaster:8140
Notice: Catalog compiled by puppetmaster
Info: Applying configuration version ...
Notice: Applied catalog in ...
```

Your final successful run also generated the HTML containing the Hiera and Facter values. 

---

# 14. Check Apache

```bash
sudo systemctl status apache2
```

**Why:** Confirms that Apache is running.

Look for:

```text
active (running)
```

Press:

```text
q
```

to exit.

---

# 15. Check generated HTML

```bash
sudo cat /var/www/html/employee_portal/index.html
```

**Why:** Confirms that Puppet actually generated the final HTML file.

You should see information such as:

```text
Company Employee Information Portal
Welcome to the Company Employee Portal
Information Technology
puppetmaster
10.0.2.15
Ubuntu
```

This matches the successful generated HTML from your practical. 

---

# 16. Open the Employee Portal

Open your browser and enter:

```text
http://localhost/employee_portal/
```

**Why:** Apache serves the HTML page through the browser.

Your final result should display:

```text
Welcome to the Company Employee Portal

Company Employee Information Portal

Department: Information Technology

Hostname: puppetmaster

IP Address: 10.0.2.15

Operating System: Ubuntu

This portal is deployed automatically using Puppet.
```

# Final folder structure

After completing everything, your structure should be:

```text
/etc/puppet/
├── hiera.yaml
└── code/
    └── environments/
        └── production/
            ├── data/
            │   └── common.yaml
            ├── manifests/
            │   └── site.pp
            └── modules/
                └── employee_portal/
                    ├── manifests/
                    │   └── init.pp
                    └── templates/
                        └── index.html.erb
```

```text

11. Check Apache
12. Check generated HTML

```
