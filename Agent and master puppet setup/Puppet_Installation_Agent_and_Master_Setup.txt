================================================
PART 15 — CERTIFICATE MANAGEMENT
================================================

On Ubuntu, list pending certificate requests:

sudo puppetserver ca list

List all signed certificates:

sudo puppetserver ca list --all

The Windows certificate in this setup is:

desktop-7mq1kll.lpu.com

To sign a genuinely pending request:

sudo puppetserver ca sign --certname desktop-7mq1kll.lpu.com

IMPORTANT:
Only sign a certificate when it appears in the pending certificate list.
If "ca list" says "No certificates to list", use:

sudo puppetserver ca list --all

to check whether the certificate is already signed.
